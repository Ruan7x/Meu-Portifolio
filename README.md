# Portfólio — Ruan Fabricio

Página única (index.html) com uma seção "O que estou ouvindo agora"
conectada de verdade à API do Spotify.

- O visitante não vê nada da sua conta além da faixa atual.
- O Client Secret e o token de acesso ficam só no servidor.
- `/login` e `/logout` são protegidos por uma `ADMIN_KEY` (veja `.env.example`).

Veja o `SETUP.txt` para rodar localmente.
